IAmNotYourFan

Find the accounts you follow that don’t follow you back on X.

Current status (local dev):

  1. Run pnpm dev
  2. See beautiful hero + full scanning workspace with tabs, exports, ignore list
  3. Preview mode works great on localhost
  4. Real X scanning (auto-scroll + collection) is functional when pasted on x.com/following

Settings modal, persistent ignore list, and high-fidelity UI are already implemented.

To test the full beautiful UI on your real profile:

1. Run: pnpm build:console && pnpm make:console-bundle
2. Open dist/iamnotyourfan-full-console.js
3. Copy the contents and paste it in the console on x.com/yourname/following

The script will do a full page takeover and automatically start scanning your real following list.
